NEXORA FRONTEND STARTER
=======================

Pages included:
- index.html                 Home
- shopping.html              Product listing, category filters, search and sorting
- product.html?id=1          Product details
- cart.html                  Shopping cart
- wishlist.html              Wishlist
- login.html / register.html Account UI
- checkout.html              Checkout demo
- admin.html                 Admin dashboard
- admin-products.html        Product management demo
- admin-orders.html          Order management placeholder

How to run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Navigate using the navbar and page links.

Important:
- This is a frontend learning/demo starter using HTML, CSS and vanilla JavaScript.
- Cart and wishlist are stored in browser localStorage.
- The product catalogue is currently a JavaScript array in js/app.js.
- Login, checkout and admin actions are demonstrations only.
- Do not use this as a production store or collect real passwords/payment details.
- Next backend step: replace demo product data and actions with Node.js + Express REST APIs and a database.
- Replace sample image URLs and product data with your own licensed product assets and accurate information.
